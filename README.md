# 喵德尔

**猫色溯源实验室。**一个猫毛色遗传的交互式科普工具：给定一只猫的花色，反推它爸妈可能长什么样、它孩子会长什么样。

起因：楼下有一只长毛橘色狸花猫和一只灰白相间的短毛狸花猫，好奇它们的来历。顺带发现一件事——**「狸花」不是品种，是花色**。

- 线上版本：https://claude.ai/code/artifact/f20cf7ef-cbea-431b-8407-839790051725
- 本地开发：`npm install && npm run dev`
- 单文件产物：`npm run build` 生成的 `dist/index.html` 可直接用浏览器打开，仍是零依赖、零后端（字体走 Google Fonts 外链）

## 市场定位

调研过现有产品，三个空白：

1. 现有工具**全是正推**（父母 → 幼崽），几乎没有反推
2. 现有工具**全是给繁育者的**，术语门槛高（Messybeast、各家猫舍自建表格，以及近两年大量 AI 生成的计算器农场站）
3. **中文世界基本为零**——只有知乎豆瓣的图文长贴，没有交互工具

目标用户是**街上偶遇猫的路人 + 想搞懂自家猫的养猫人**，不是繁育者。所以不做多位点精度、不做导出、默认不甩术语。

## 遗传模型

五个位点，覆盖中国街猫约 95% 的花色：

| 位点 | 含义 | 说明 |
|---|---|---|
| `O` | 橘色 | **X 连锁**，整个模型里最有意思的部分 |
| `D` | 稀释 | 隐性，黑 → 蓝(灰)，橘 → 奶油 |
| `A` | 虎斑开关 | 隐性 `aa` = 纯色。**对橘猫无效** |
| `S` | 白斑 | 显性，半显性且变异极大 |
| `L` | 毛长 | 隐性 `ll` = 长毛 |

**明确不做**：`W` 显性全白、`T` 虎斑纹路细分（鲫鱼纹/古典纹/点纹）、`C` 重点色、银色抑制基因、金渐层宽带基因、`B` 巧克力色。

### 状态空间

- 公猫 162 种基因型（O 有 2 种 × `3^4`）
- 母猫 243 种（O 有 3 种 × `3^4`）
- 父母配对 39,366 组

小到可以暴力穷举。实现上按位点分解求解——因为**位点独立且目标是乘积集**，分解结果与全量穷举完全等价，只是快得多。正推和反推是同一引擎的两个查询方向。

### 只给三态，不给概率

输出只说 **必然 / 可能 / 不可能**。

要给概率就必须知道中国街猫群体的等位基因频率（比如 `dd` 稀释基因占比），这个数据没有可靠来源，**编一个出来是不诚实的**。

## 核心洞察：反推的正确输出是断言，不是枚举

合法的父母组合有几千对，全列出来是垃圾。但答案其实极其锐利：

> 输入「长毛橘色公猫，无白斑」
>
> - **它妈妈必然带橘色**——只可能是橘猫、奶油猫、玳瑁或三花
> - **它爸爸的花色完全不受限制**（只给 Y 染色体）
> - **爸妈双方都携带长毛基因**，哪怕它们自己都是短毛
> - 爸妈都不可能是几乎全白的猫

同理，正推也有不依赖配偶的断言：

- 橘色公猫 → **女儿全部带橘色**，一只都跑不掉；儿子橘不橘跟它毫无关系
- 橘色母猫 → **儿子全部是橘色系**
- 玳瑁/三花母猫 → 儿子分成两拨，一半橘一半非橘
- 纯黑母猫 → **它爸爸绝不可能是橘猫**

## 已验证的断言

跑过四组用例，边缘集与联合约束均正确：

| 用例 | 关键验证点 |
|---|---|
| 长毛橘公猫·无白 | 妈妈 O ∈ {OO, Oo}；爸爸 O 不受限；爸妈 L 均排除 `LL`；爸妈 S 均排除 `SS` |
| 三花母猫 | 爸妈边缘集均不受限（「一橘一非橘」是**联合**约束而非边缘约束）；A 排除 `AA` |
| 纯黑短毛母猫·无白 | 爸爸 O 只能是 `o` → 橘猫/奶油猫/橘白猫全部排除 |
| 蓝白短毛公猫 | 妈妈不可能是纯橘猫，但可以是三花 |

## 设计决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 核心用户 | 路人 + 养猫人 | 排除繁育者的精度与导出需求 |
| 主界面 | 「猫的身份证」一屏 | 一屏讲完全部价值 |
| 输入方式 | 常见花色卡片 + 可展开六维度面板 | 低门槛入口 + 高教育价值；**输入面板本身就是最重要的教学时刻** |
| 反推呈现 | 断言为主，例猫为辅 | 枚举无价值，洞察才有 |
| 孩子预测 | 先讲不依赖配偶的断言，再给预设配偶 | 解决「缺配偶就没法算」的逻辑漏洞 |
| 术语层级 | 默认说人话，符号可展开 | 路人不被吓跑，深挖者有东西看 |
| 白斑建模 | 五级滑块而非三态 | `S` 实际是半显性且变异极大 |
| 渲染器 | 可插拔接口 `(基因型, 随机种子) → 图` | 同一基因型 roll 出不同白斑，科学上正确 |
| 交付形态 | 单文件 HTML | 零部署、手机可玩、可分享 |
| 「不可能」的编码 | 灰度化 + 划线，不用色相 | 把红橙色留给橘猫 |

## 视觉

- **配色取自真实猫毛色素**：橘猫橘 `#B85714`、狸花 agouti 褐 `#907B5B`、蓝猫灰 `#7F8990`、奶油 `#F0D5A8`。页面底色是冷调实验台灰，暖色只出现在猫身上
- **字体**：思源宋体（标题与断言句）+ 系统 CJK 无衬线（正文）+ IBM Plex Mono（基因型符号）
- **版式**：左侧仪器面板、右侧档案竖列，用 ↑上一代 / ●这一只 / ↓下一代 作 eyebrow——方向本身编码代际信息
- 支持浅色/深色主题；猫的剪影带描边，所以黑猫在深色背景、白猫在浅色背景都看得见

## 模型边界（页面底部也写了）

- **对纯血猫会给出错误答案**：暹罗和布偶的重点色、英短金渐层的宽带基因、银虎斑的抑制基因、巧克力色都不在模型里
- 白斑相关的反推结论天然比其他位点模糊。**「三花」和「玳瑁」的区别只是白斑多少，不是不同的基因**
- 玳瑁/三花几乎必然是母猫，例外是 XXY 的克氏综合征公猫（通常不育）
- 猫图是占位示意，不是写实图鉴
