## 基于软 3D 方向的解剖参考

1. `anatomy-01-landmarks.png`：同一只猫的正、侧、后、俯视与三分之四视图；用于锁定头身比、背线、关节点和四足落点。
2. `anatomy-02-skeleton-overlay.png`：半透明外形内的骨骼叠层；用于观察肩胛、胸腔、脊柱、骨盆、腕跗关节和尾根。
3. `anatomy-03-surface-muscles.png`：毛发表面与表层肌肉体块的对照；用于处理肩颈、胸背、腹线、臀腿和尾根转折。

三张图以 `concept-03-soft-3d.png` 为视觉与比例基准，由生成式工具制作。可用于概念设计、建模和动作校准；细小骨数、肌群边界与附着点仍须以下方的非 AI 资料复核，不可用于医学或兽医判断。
