# 单猫 3D 可行性验证

状态：第二版黑白参考猫候选场景已完成，本地功能验证通过；造型和真实手机性能待验收，自动工作到此停止。不是完整渲染器升级。

## 本轮更新：黑白参考猫

用户补充四张黑白成年短毛猫参考，并授权在无人值守时完成一个可运行示例，限制额外迭代和消耗。因此本轮沿用 `?preview=cat3d`，改为黑白站姿猫 / 同模型纯黑切换，增加实际眨眼形变、间歇呼吸/尾摆和按钮缩放。白斑仅为这个个体的示例遮罩，不引入白斑等级或遗传输入，不扩大到亲缘关系。

采用 `bpy` 建模与固定渲染反馈，保存可编辑场景和独立 GLB，旧技术样板文件保留。原生界面已检查可访问，但本轮未通过 GUI 雕刻；没有安装 MCP。以下原始范围和实测记录属于第一版历史，最新产物与验证以[第二版制作记录](../../art/cat3d/reference-v1/README.md)为准。

本轮验证：23 文件 / 2,250 测试、类型检查、单文件构建通过；换色/键盘/旋转/缩放/回应/减少动态效果、四种视口、离线 HTML 和 WebGL 丢失降级通过。约 62,864 三角形 / 15 draw calls。美术仍低于参考图，明确保留后续人工验收，不继续自动打磨。

## 场景与边界

在独立 `?preview=cat3d` 入口展示一只短毛坐姿猫。只验证转动观察、橘色虎斑／纯黑切换和一个点击回应，不接亲缘节点、不替换主界面、不增加遗传输入或品种。

本实验接续 [视觉计划](./2026-09-06-visual-interaction-exploration.md)。用户认为已有 SVG 猫的造型缺乏吸引力，因此独立验证真正的 3D 方向，而非继续叠加 SVG 光影。总体规划阶段 2→3 的依赖和阶段 6 的完整品种／花色范围不变。

## 制作约定

- 先用概念图明确圆脸、大瞳孔、放松体态的角色方向。概念图不是 Blender 渲染或浏览器效果，不以它证明模型质量。
- 首次本地试验使用 Blender 可复现脚本，产出可编辑 `.blend` 和网页 `.glb`。不调用额外付费图生 3D 服务，也不下载授权不明的猫模型。
- 用独立 Three.js 预览组件替代本实验的「仅 SVG」限制；旧 SVG 实验、原界面和黄金基线保持不变。
- 模型、代码内嵌后仍须单 HTML 可打开，不依赖在线模型、环境贴图、CDN 解码器或后端。
- 橘猫显示虎斑，黑猫为纯黑；共用网格、姿态和面部，切换只影响毛色。仅覆盖这两个合法表型，不宣称支持完整 CoatSpec。
- 手机核心操作不能依赖 hover；用按钮作为拖动与点击的替代入口，支持减少动态效果。设备不支持 WebGL 或模型加载失败时提供明确错误和返回 SVG 入口。

## 验收门槛

1. 审美：实际网页猫在正面、三分之四视角和小尺寸下均可接受；用户判断优先。概念图与实际模型应并列区分。
2. 一致性：切换颜色不改模型、眼睛、姿态；黑色不能残留橘色色块。
3. 交互：鼠标／触屏旋转、键盘按钮、重置视角、点击回应、减少动态效果、卸载资源回收。
4. 工程：类型与旧测试通过，新增场景契约检查，构建无额外运行时资产，离线打开和无 WebGL 降级可用。
5. 性能：记录模型三角形数、包体和浏览器实测环境。桌面无头或手机视口模拟不等于真实手机 GPU／电量测试；真机性能未测时明确记为待验证。

只有本场景通过才扩大到白斑、玳瑁、毛长与亲缘节点。若本地脚本造型达不到概念方向，停止扩大代码，转为评估经过确认的基础模型或图生 3D 资产。

## 概念图提示词摘要

使用内置 imagegen，生成同一只猫的三分之四、正面、侧面造型参考：原创动画风短毛橘色虎斑猫、饱满脸颊、大而圆润的眼睛、较大深色瞳孔、短口鼻、松弛坐姿和完整尾巴；柔和中性光、无道具文字、无白斑。正式实时模型简化概念图中的毛发细节。

完整提示词、原始概念图、可编辑模型与实际效果见[制作记录](../../art/cat3d/README.md)。

## 实测结果（2026-09-07）

- 入口：`?preview=cat3d`；原 `?preview=cat` 和默认主界面保持可用。
- Blender 5.2.1 LTS Apple Silicon 官方 DMG，通过官方 SHA-256 校验；临时挂载运行，未安装到系统 Applications、未安装 MCP 插件或调用付费资产服务。
- 原创 Blender 脚本产出约 1.5 MiB GLB；场景共 80,126 个三角形、29 次 draw call（含接触阴影）。这是资源计数，不是真机帧率。
- `npm run check`：23 个测试文件 / 2,249 测试通过，包含旧 SVG 360 状态，未改遗传引擎、旧渲染器或冻结基线。
- 完整单 HTML 约 3.05 MB，gzip 约 1.37 MB；由于单文件交付，默认界面也承受整体产物增量，不应把本实验的包体视为正式交付预算已通过。
- 独立无头 Chromium（SwiftShader）验证：换色像素变化、键盘选色、左右旋转、拖动、重置视角、实际点头转头、减少动态效果、静止停止绘制、320/390/768/1440 视口、手机选择时预览不被遮挡。
- 阻断所有 HTTP(S) 请求后，构建出的 HTML 仍可加载 GLB、换色、返回 SVG／原界面。禁用 WebGL 时可以进入明确错误提示并返回 SVG。
- 测试过程中修正 React StrictMode 重建 canvas 的 context-loss 问题；清理时重置 GL 状态并释放几何体／材质／纹理、监听器、observer 和渲染器。
- 当前实际模型较概念参考更接近玩偶，眼睛、耳朵和表面质感仍有差距。技术链路通过 ≠ 审美通过；当前不进入多花色、长毛、亲缘节点或全站替换。
- 未做真机 GPU、耗电和长时间温升测试，也未做完整骨骼动画；当前回应是头部独立节点的轻微旋转。
