# 五花色共用身体验证

状态：独立样板已实现，技术和桌面视觉对照完成，待用户体验验收。承接遗传与 3D 覆盖评估的资源优化验证，不代表总纲新位点或正式主图接入完成。

## 范围与实现

入口 `/demos/tripo-cat/shared-coats.html`。奶油、蓝狸花、蓝白、淡三花、玳瑁共用一份 body.glb，花色由材质 glTF 和独立 JPEG 原字节提供。未重绘、重新压缩图片或调用生成服务，新增积分消费为零。

`tools/cat3d/build-shared-coats.py` 先核对五个源 GLB 的 SHA-256，再检查 geometry/UV/accessors/primitives/节点变换一致；保留原 JPEG 和材质参数，生成不带贴图的身体与五套材质。任何来源或布局不符立即失败，不强行套用。已存在但内容不同的输出拒绝覆盖。

正常换色复用当前场景和 geometry，按需读材质。过期异步结果释放，不覆盖新选择；切换完成释放旧材质和贴图。模式切换及离开页面释放场景；失败清空画布并允许重试。对照模式使用原始 GLB，会额外加载身体，不计为共享流程。

现阶段依靠 HTTP 缓存复用已下载图片，每次重新解码并上传 GPU；不设全库显存缓存。未实现请求取消，快速点击可能发出最终未使用的图片请求，但过期结果被释放。没有将整库打包进正式首页。

## 实际大小

- 原五套总计：13,587,944 字节。
- 共享身体＋五套材质/图片：4,124,463 字节，减少约 69.6%。
- 身体约 2.37 MB；每套材质与图片约 0.32–0.38 MB。首次仍需身体＋当前花色，主要收益是后续切换与全库去重。
- MB 为十进制文件长度，不等于显存、实际网络传输或手机跑分。页面时间包含缓存、解码和首次绘制，不保证弱网耗时。

## 恢复与存档

原始模型归档位于 `~/.local/share/meowndel/soft-low-poly-cat-2026-09-16/`。

```sh
node tools/cat3d/restore-tripo.mjs
python3 tools/cat3d/build-shared-coats.py
pnpm run dev --host 127.0.0.1 --port 4181
```

派生素材保存到归档内 `shared-coats/`；项目 `demos/tripo-cat/shared-assets` 是忽略的目录链接。Git 只存脚本、样板、含大小和 SHA-256 的 manifest 与文档。外部原始档需另行备份。
