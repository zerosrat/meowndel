# 11 花色分组复用与五档白斑验收

状态：独立样板、技术验证完成；11 套复用和白斑观感待用户本轮验收。承接全量田园猫 3D 复用计划的第 1–2 步；不包含长毛、新花色生成、遗传结果改造或正式主图接入。属于总纲阶段 1 后视觉支线。

## 验收入口

`/demos/tripo-cat/grouped-coats.html`

1. 选择 11 种花色，切换“共享版 / 原版对照”，观察造型、毛色与正侧背。
2. 点“用纯黑试”或“用狸花试”，在无白斑、零星白、中量白、大面积白、高白间切换。
3. 重点判断白斑边缘、前腿、胸腹、眼鼻耳与背面的衔接。原版对照不叠加白斑；其他九种花色禁用白斑试验。

## 完成内容

- 五组身体：橘；狸花/黑白；三花；奶油/蓝狸花/蓝白/淡三花/玳瑁；纯黑/纯蓝灰。
- 生成 5 个无材质身体 GLB、11 个材质 glTF、按 SHA-256 去重的原始 JPEG。图片不重新编码，保留眼鼻耳与原材质参数；跨组换身体，同组仅换材质。
- 共用法线文件，输出 manifest 记录 SHA-256 / 字节数 / 原文件 / 旋转角 / 分组。
- 实际全库：30,471,232 → 15,392,492 字节，减少约 49.5%。不包含旧档、旧五色样板的并存占用。初次访问只读当前身体与材质；不预载全库，不把源档上传或放进 Git。
- 白斑使用物体表面位置的渐进距离场，贴在毛皮上随身体转动，保留原法线与实时灯光。阈值切换不下载贴图，也不重建身体。
- 眼鼻耳保护区域经实际模型点位校准；修正初版覆盖眼睛和耳内的问题。调试用点位读取入口已移除。
- 异步过期任务释放、不覆盖最后选择；切换组、失败和卸载释放资源。原版对照有额外加载，不用其流量冒充共享模式。

## 白斑边界与待验收点

- 五档是典型美术预设，没有按皮肤表面积校准，不与引擎 white=0–4 建立正式映射，也不输出遗传概率。高白仍保留耳部/尾端色块，不代表显性全白。
- 白色来自着色器叠加，原底色/纹路图片保持不变。中高白区会比原毛皮更简化、更有切面感；不是新生成的专用贴图。
- 鼻色、眼色保持原图，不模拟白斑与皮肤色的所有变化；嘴部细线、耳边与面部自然度需用户确认。
- 当前形状固定、没有种子变化和真实个体斑块复原；只在纯黑、狸花两套做试验，不能据此宣布 100 状态已覆盖。
- 美术不过关时改做对应档位的专用贴图，仍可复用身体；不把技术通过等同于全量程序白斑方案获认可。

## 验证记录

- 分组生成器先运行只读审计，核实全部 11 个来源 SHA-256、几何、UV、节点变换；重复执行得到相同资源与总大小，不覆盖不同内容输出。
- 11 套共享和原版逐一载入，状态可旋转；纯黑原版/共享目视对照未见明显差异。共享材质保留源参数和图片字节；浏览器截图字节比较并非全相等，因此不宣称像素级无损。
- 无白到高白切换可用；纯黑与狸花的中量/大面积/高白正侧背检查，眼睛保持原虹膜，白斑跟随模型旋转。用户美术验收未完成。
- 干净页面纯黑→纯蓝灰：身体读数 1 不变；狸花→黑白：身体读数 2 不变；五色组依次切换后身体读数 3 不变。跨组快速切换最终停在狸花，只有一个 canvas。
- 临时移走 `black.gltf`，出现加载失败并禁用角度/白斑按钮；恢复后“重试”直接成功，白斑状态恢复。测试文件已全部归位。
- 390px 窄屏无横向溢出、单个 canvas，猫和按钮可见可操作；未测试真实手机 GPU 性能或弱网。
- 样板严格 TypeScript 检查通过，`pnpm run check` 通过（28 文件 / 2268 测试，生产单 HTML 构建）。生产首页及遗传冻结基线没有修改。
