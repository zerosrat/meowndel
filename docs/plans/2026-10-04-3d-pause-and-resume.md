## 恢复步骤

1. 从当前代码继续，或在独立工作区检出 `codex/3d-paused-2026-10-04`。不要对正在推进的 2D 工作区执行硬重置。
2. 准备 Node 24、pnpm 11.5.2 与项目依赖。确认外部归档在上述路径；换机器需先恢复素材，不能仅克隆 Git 后直接启动。
3. 在仓库根目录运行：

   ```sh
   node tools/cat3d/restore-blocky.mjs breed-manifest.json
   python3 tools/cat3d/verify-breed-coats.py
   pnpm run dev --host 127.0.0.1 --port 4181 --strictPort
   ```

4. 打开 `http://127.0.0.1:4181/demos/tripo-cat/breed-study.html`。恢复脚本应报告 `Cat study assets verified and restored.`；页面应返回 HTTP 200，浏览器中还需确认模型实际加载。仅 Vite ready 或页面 200 不代表模型正常。
5. 需要旧实验时：原 11 款用 `node tools/cat3d/restore-tripo.mjs`，块状单猫用 `node tools/cat3d/restore-blocky.mjs`。共用身体实验分别参考 `build-shared-coats.py`、`build-grouped-coats.py`、`build-natural-white.py`；它们会生成派生资源，按需要运行，不是恢复最新品种页的前提。
