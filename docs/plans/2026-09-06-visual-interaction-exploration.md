# 视觉与亲缘探索计划

日期：2026-09-06
状态：本轮范围已确认；实施暂停，尚未修改业务代码。本文目前记录设计方向和范围，执行步骤与验收清单待补充。

## 范围

假设当前已有工作完成，讨论接下来的视觉与交互优化。承接 `2026-09-06-cat-color-v2-design.md` 中尚待对齐的整体视觉与动效方向，并细化与猫渲染、属性输入及亲缘探索有关的体验。此文档不表示前述设计已经实现。

最新范围原则（用户已确认）：先美化服务于主要功能的视觉与交互，不急于增加额外功能。以下「已确认方向」包括长期认可的方向，不等于全部纳入本轮。

自动保存、关闭页面后恢复探索暂不做。多份探索、命名与收藏也不纳入本轮提案。

## 已确认方向

1. 核心体验：选出一只猫，直观看到属性如何改变它，再沿亲缘关系继续探索。用户可以点中感兴趣的结果猫，接着探索它。
2. 猫的视觉：偏自然、略可爱的风格化插画，以柔和明暗表现体积，保留猫的体态和可辨认的花色、毛长。配合眨眼、呼吸、摆尾及点击回应等少量动作；具体动作清单与强度尚未定稿。
3. 属性反馈：选择属性时，让变化在猫本身得到清楚反馈，例如橘色变为奶油色、白斑变化区域得到突出。最终控件与反馈组合尚待细化。
4. 设备支持：desktop 与 mobile 共享探索逻辑，分别适配布局。桌面可展示关系并在侧边编辑；手机聚焦当前猫和相邻亲缘，以底部详情承载操作。核心功能可通过点击完成。
5. 连续探索（后续方向）：保留亲缘来源及已知遗传约束，未知的隐藏基因继续保持未知。界面明确区分可能的后代与真实出生的猫。见 [ADR 0001](../adr/0001-preserve-ancestry-during-exploration.md)。
6. 节点操作方向：点击先选中，猫做轻微回应，并展示花色、关键解释和后续操作；关系扩展由明确操作触发。本轮仅展开当前猫的父母和孩子，不继续展开多代。
7. 分支编辑方向：已经展开亲缘的猫修改时建立对比分支，保留原探索；尚未展开的猫直接修改。用户认可这一行为，但提出优先美化主功能，因此本轮提案暂缓分支机制。
8. 属性反馈组合：选项显示对应色样，猫呈现连续变化，受影响的结果短暂强调并给出简短解释；变化被其他特征遮住时说明原因。

## 本轮确认范围

- 猫的绘制质感、花色与毛长辨识度，以及少量状态回应。
- 属性控件的色样或图示、选中态，以及与猫图和结果的联动反馈。
- 将主体、候选父母、配偶和可能的孩子组织成清楚的局部亲缘关系；以选中、查看解释和已有配对操作为中心。
- 桌面与手机布局适配，特别是修改属性时能够看到猫图反馈。
- 仅根据当前猫展开其父母和孩子；多代连续展开和对比分支留待后续，保留其设计约束供后续使用。

用户已确认上述范围，并要求在独立 worktree 修改，不污染当前 feature 分支。

## 待细化

- 本轮节点只承载当前猫的局部关系、查看解释及已有配对操作。
- 范围确定后的控件布局、关系线及候选集合的表达、未知信息和不兼容状态、动效强度与减少动态效果的适配。
- 连续探索及分支编辑的具体节点表示和约束传播留待相应功能进入范围时讨论。
