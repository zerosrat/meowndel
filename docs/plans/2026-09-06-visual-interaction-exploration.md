# 视觉与亲缘探索计划

日期：2026-09-06
状态：评审修订和「一只猫＋属性控件」独立样板已完成，待用户确认视觉；确认后才推广到主界面和亲缘节点。

## 与总体规划的关系

本计划细化[总体规划](./2026-09-06-cat-color-v2-design.md)的视觉方向，并明确一次顺序调整：阶段 1 完成后，先对现有五位点模型做局部视觉与交互验证，降低完整界面改造的审美返工成本。这不表示阶段 2–7 已完成，也不替代阶段 6 的完整渲染器升级。

总体规划中「阶段 2 的模型契约先于阶段 3 的新位点」仍是硬约束。阶段 6 的五剪影、重点色及新增毛色依赖阶段 5 的品种与花色范围；本轮只验证现有猫体态和花色，暂不制作英短、布偶等品种专属剪影。分离轮廓、底色、纹路、白斑、阴影和面部，给后续扩展留出边界，但不承诺新位点接入时完全无需调整美术。

## 本轮范围

- 猫的视觉：偏自然、略可爱的风格化插画，以柔和明暗表现体积，清楚区分已有花色和毛长。用少量眨眼、呼吸或点击回应增加生命感。
- 属性反馈：控件使用色样或图示；猫图对应变化清晰可见。性别等不改变外观的属性用文字反馈，不能杜撰视觉差异。
- 局部关系：只围绕当前探索主体展示候选父母、配偶及可能的孩子。点击节点用于选择、查看解释及已有配对联动，不将候选设为新主体继续展开祖辈或孙辈。
- 节点表示一类候选猫，插画是代表形象，不意味着唯一已知基因型、真实血统或同一窝孩子。两侧父母候选保留联合兼容性约束。
- 桌面与手机共享操作语义、分别适配布局。核心操作能用点击及键盘完成；编辑属性时能看到猫图反馈。

## 当前交付：单猫视觉样板

通过独立预览入口展示一只猫和一组外观控件，暂不替换主界面。控件覆盖底色、浓淡、虎斑、白斑及毛长，以便验证配色、轮廓与不同类型的变化；不加入品种、配偶、保存或亲缘展开。

按现有规则归一化输入，例如橘色系始终显示虎斑，不能让样板画出引擎不支持的状态。固定图案 seed，使属性对照稳定。重点评审猫的气质、花色辨识、反馈是否清楚，以及手机上编辑与预览是否能同时使用。

## 白斑与动效约定

- 「连续反馈」不等于所有形状都必须 morph。底色可插值；白斑层和毛长轮廓可交叉淡入淡出。
- 旧渲染器的白斑等级 0 无形状，1 为嘴套、胸口和两只白袜，2 为波浪边界，3 在波浪边界之外增加眉心白条，4 继续扩大覆盖。1→2 有拓扑变化，2→3 也增加形状；不用强行改成一种白斑形状来迁就动画。
- 高亮表达的是当前示意图的变化区域。界面同时说明「白斑位置仅为示意，等级不能确定具体位置」；等级对基因型为多对多，不把视觉位置或精确面积当成遗传结论。
- 同一 seed 下保持图案稳定；改变其他属性不额外抽样白斑。快速连续选择以最新输入为准，不能残留旧状态。
- 支持 `prefers-reduced-motion`：取消循环动作和过渡，保留即时且清楚的选中态、猫图与文字反馈。

## 工程与验收约束

- 保留单个 `dist/index.html` 交付，双击可打开；除现有字体外链外，不新增运行时网络依赖或后端。使用已有 React、内联 SVG 和 CSS 完成样板，不引入图编辑或动效框架。
- 保持遗传计算与渲染分离，不用视觉试验修改遗传结果。
- 保留 `tests/fixtures/legacy-golden.json`。样板采用独立渲染组件，不改旧 `catSVG()`、`tools/build-states.ts` 及 360 状态的旧 SVG 等价测试，因此当前遗传和渲染基线继续生效。
- 后续替换主渲染器必须单独制定测试迁移：旧引擎行为回归继续保留；新渲染用可观察语义和视觉检查验证。不能整体重录 legacy 基线，或把整个 `selfSvg` 无条件放行。
- `tests/render/catSVG.test.ts` 是独立的直接字节比较，不经过 drift 的 NORMALIZERS；仅新增 NORMALIZER 无法解决新旧绘图不同的问题。预期遗传变化应由针对性 NORMALIZER 或精确 INVARIANT 证明，而非笼统豁免。
- 旧 `catSVG()` 的模块级 UID 与调用顺序有关。新组件使用实例隔离的 SVG 标识；图案随机性只由显式 seed 决定，避免多个预览之间的遮罩串用。

## 实施顺序与验收

1. 修订术语、ADR、总体规划入口与本计划，明确当前能力、后续依赖及范围。
2. 实现单猫样板：分层插画、外观控件、稳定图案、轻微动作和减少动态效果适配。
3. 运行 `npm run check`，确认类型、现有遗传/渲染回归及单文件构建通过。增加有实际风险覆盖价值的控件联动与 SVG 标识测试。
4. 浏览器检查桌面和手机：选择颜色及浓淡、切换白斑 0/1/2/3/4、切换毛长、橘色虎斑约束、键盘操作、减少动态效果。检查溢出、遮挡和控制台错误，并验证构建后的独立 HTML。
5. 交付可打开的样板与验证结果，等待用户对视觉的反馈。主界面、结果反馈和亲缘节点接入留到样板确认后。

## 已确认但推迟

- 将结果猫设为新主体继续探索多代；保留来源的条件约束与亲本联合关系，未知基因继续保持未知。其前置能力见 [ADR 0001](../adr/0001-preserve-ancestry-during-exploration.md)。
- 修改已展开的猫时建立对比分支，保留原探索。
- 自动保存、关闭后恢复、多份探索、命名和收藏。
- 完整品种剪影、重点色及其他新增位点的渲染能力，按总体规划后续阶段推进。

## 样板确认后再细化

局部亲缘节点的排列、关系线与候选集合表达，详情位置，不兼容状态及受影响结果的强调方式。当前样板不提前实现这些功能。
