## 四花色独立贴图（当前验收轮）

### 已确认方向与范围

用户否定程序生成的花纹观感，改用真实猫毛色结构作为参考；本轮将狸花、黑白、三花推进到与原橘猫相同的可旋转网页状态，一起验收。保留原造型，不扩展英短，不接遗传引擎。

### 实施

1. 在 Tripo 为三个花色各复制原模型，独立生成完整贴图；狸花与黑白使用文字描述。
2. 三花两次文字生成未达到三色要求，排除；改为内置 imagegen 编辑原概念，上传黑橘白参考图，按图生成纹理。实际得到明确三色色块，画风较文字生成更接近原橘猫。
3. 导出 4K GLB 并保留原档；本地 Blender 减至约 8 万面、2K 贴图，网页按需加载。素材均归档 Git 外，仓库只保存代码、来源和恢复说明。
4. 当前入口新增四花色单独切换、四猫并排和统一正侧背视角；旧程序花纹页面移至 `procedural.html` 作历史实验。

本轮 Tripo 实际消费 115 积分（复制 15 + 五次贴图 100），余额 3495 → 3380。没有购买订阅。

### 验收要点与后续

- 狸花和黑白贴图偏细腻写实，三花和原橘猫偏低多边形插画；需要用户判断是否统一为参考图驱动的风格。
- 狸花背部比正面暗、条纹弱，黑白背部有明显几何明暗分面；保留真实结果供本轮验收，不声称已完成美术精修。
- 这轮仅验证固定花色样板。后续才考虑语义遮罩、任意毛色、引擎映射、移动端性能与英短体型。
